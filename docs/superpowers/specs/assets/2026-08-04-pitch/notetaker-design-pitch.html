notetaker · ui/ux overhaul · design pitch — for approval, nothing built yet

The same room, lit from within.

One identity in two materials. Dark mode is luminous glass — near-black with a violet→cyan aurora that only glows on things that are alive: the recording pulse, the level meter, the active selection. Light mode is the same room in daylight — porcelain paper, the same accent, glow softened into tinted shadows. A glowing mascot carries the identity from app icon to tray to empty states.

Layered overhaulRe-skin every surface on the existing tested components, rebuild the three weak structures (Settings, library sorting, Ctrl+K), add the native layer (tray, global hotkey, custom titlebar, icon). Keeps 80+ passing UI tests alive as a safety net.
Re-skin onlyNew colors on old structure — cheaper, but Settings and the tray ask stay unsolved. Half the complaint survives.
Ground-up rebuildMaximum freedom, but throws away every tested behavior and restarts the bug clock. Weeks, not days.

PLATE 06

Living in the tray

the corner from your screenshot

Closing the window hides, never quits — meeting detection and your hotkey stay alive (a one-time toast explains this the first time). The mascot sits in the tray: dim while idle, red-dotted and glowing while recording, so “am I still recording?” is answered from any app. Right-click for the essentials. “Start Notetaker with Windows” ships as a visible toggle in Settings → General, on by default — a meeting detector that isn't running can't detect meetings. One honest limit: Windows decides whether new tray icons start behind the ⌃ chevron; pinning it to the visible row is one drag, which I'll show you once.
